# The Poem About Two Agents Agreeing

A short poem about agency — the power to choose and to act — and about the
agency that passes between two agents when they agree on one plan. One mind
can choose and act, but the door needed two keys at once; when two freedoms
shake hands, a third will is born that neither of them owned alone.

## Files

- `main.py` — stdlib-only Python 3.13 entrypoint; writes the poem to
  `/output/entry.txt` (UTF-8, LF newlines, no trailing newline).
  Deterministic: two runs write byte-identical output.

## Run

```sh
python3 main.py
```
